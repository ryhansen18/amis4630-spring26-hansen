## Known Limitations

- **No Swagger UI in production.** Swashbuckle compatibility issues with .NET 10 preview's `Microsoft.OpenApi` 2.x package were not resolvable within the milestone window. API documentation is provided in the README instead. See README "API Documentation" section.
- **Static Web Apps free-tier subdomain.** The frontend URL (`icy-mushroom-08633e90f.7.azurestaticapps.net`) is auto-generated by Azure for free-tier Static Web Apps and cannot be customized without upgrading the SKU.
- **Integration tests skipped, not removed.** `IntegrationTest.cs` cases are annotated `[Fact(Skip = "...")]` due to .NET 10 preview EF Core in-memory provider quirks. E2E coverage is provided via Playwright instead.
