## The ERD below represents the model for **Buckeye Marketplace**, outlining core data-entity interactions utilized during the journey map process. Such interactions outline core functionalities to occur. 

As for tables listed, each share key, respective, one-to-many, many-to-many relationships that capture the essential data flow for functions like order processing, user authentication, and product discovery. Ultimately, the relationships displayed how users (buyers and sellers alike) interact with the marketplace and its respective listings during a given transaction's lifecycle.
