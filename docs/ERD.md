### Relationships

The relationships above can be broken down as follows:

- **AppUser → Cart** — each user has at most one active cart, with the cart being created upon a user's first add-to-cart instance.
- **Cart → CartItems** — a cart contains many CartItem rows, one per product type (with respective quantity).
- **CartItem → Product** — each cart item points back to a Product, allowing the frontend can render title, price, and image without duplicating data.
- **AppUser → Orders** — a given user has many orders over time (their order history).
- **Order → PurchasedItems** — an order contains a snapshot of what was bought. Note that `PurchasedItem` *copies* `ProductTitle` and `Price` at order time, rather than just holding a foreign key — this means that if a product's price changes later, historical orders still show the original price paid.
- **AppUser ↔ AspNetRoles** — a many-to-many through `AspNetUserRoles`. The seeded admin user (`admin@osu.edu`) holds the `Admin` role. Standard users get `User` (or no role on register).

### Why `PurchasedItem` instead of reusing `CartItem`?

`CartItem` is transient by nature — meaning, it's deleted when an order is placed. **`PurchasedItem` is permanent, and *denormalized on purpose*** — it stores the title and price as they were at the moment of purchase. If a seller later edits a product's title or price (or deletes the product entirely), the order history doesn't change. This is consistent with how real e-commerce systems handle this; the receipt should reflect what was actually bought, not what the product looks like in the present.

### Identity Tables

Tables like `AspNetUsers`, `AspNetRoles`, `AspNetUserRoles`, `AspNetUserClaims`, `AspNetUserLogins`, `AspNetUserTokens`, and `AspNetRoleClaims` are created automatically by `IdentityDbContext` (set up in M5 via ASP.NET Core Identity). Most of them are unused in Buckeye Marketplace currently — there are no external logins, custom claims, or 2FA — but they're part of the Identity package and live in the database for consistency moving forward.
